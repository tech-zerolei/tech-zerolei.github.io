这个博客叫 **ZERO**。

它的 GitHub Pages 骨架在 2026 年 9 月就建好了，用的是 Gmeek。然后它在那里放了三个星期，标题一直是 `Blog Title`，副标题一直是 `Blog description`，头像一直是 GitHub 的默认图标。只有一篇文章，正文是「hello。」。

不是因为不在乎。是因为没想好叫什么。

---

## 为什么要写字

我做过的东西大多留在聊天记录和本地目录里：一台自己配的 Debian 服务器、几条把静态站点挂进 nginx 子路径的配置、一个叫《一根不断的线》的交互作品。它们都能跑，但没有一处写下来。等下次再遇到同一个坑，我得重新踩一遍。

这个博客就是用来解决这件事的。**写下来的东西才算真的做完。**

## 会写什么

- **服务器**：Debian、宝塔面板、nginx。怎么把一台 NAT 后面的机器接入公网，怎么在不影响已有站点的前提下挂上新东西，怎么在只能连国内源的机器上把前端构建跑起来。
- **前端**：React、TypeScript、Vite。主要是那些在真实项目里必须做的决定——为什么这里不用 Canvas，为什么那里要多写一个断言脚本。
- **作品**：做过的一些交互实验，以及它们背后的取舍。

## 不写什么

不写「10 个你必须知道的 JS 技巧」，不写没有代码的教程，不写我没亲手跑过的东西。

## 怎么写的

这个博客的每一篇文章都是一个 GitHub Issue。写完点发布，Actions 把它渲染成静态页面，提交，部署。没有后台、没有数据库、没有登录框，文章内容和它的讨论区在同一个地方。这个方案叫 [Gmeek](https://github.com/Meekdai/Gmeek)，本站用的就是它。
